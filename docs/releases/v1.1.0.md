连续拖入文件后，应用仍然自动发送和接收。此次更新减少网络确认造成的停顿，并加入基于 GitHub Releases 的自动更新。

- 文件传输使用 1 MiB 分块和最多 8 MiB 在途缓冲，连续发送，保留加密、确认、大小和 SHA-256 校验。
- 传输列表显示实际发送或接收速度。
- 默认自动检查并下载 GitHub 新版本，在传输和等待队列完成后安装并重新打开；也可以手动检查或关闭自动更新。
- 更新目录和安装包均使用 Ed25519 签名校验。
- 继续兼容 v1.0.x 的局域网传输协议，保留一次配对、菜单栏拖放、自动接收和手动删除记录。

32 MiB 加密 TCP、确认回传延迟 20 毫秒的本机对照测试中，吞吐从 10.498 提升到 255.144 MiB/s，约 24.3 倍。实际局域网速度取决于 Wi-Fi、有线网络和磁盘，不代表任意网络都能达到该数值。

v1.0.x 用户需先手动安装一次此版本，后续即可使用自动更新。已有配对密码会保留。

支持 macOS 13 及以上版本，包含 Apple 芯片和 Intel 架构。下载 ZIP，解压后将「局域快传.app」放入「应用程序」文件夹。当前采用 ad hoc 签名，首次安装可能需要在 macOS「隐私与安全性」中允许打开。
